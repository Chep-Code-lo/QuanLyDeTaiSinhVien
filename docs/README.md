# Tài liệu dự án

- `architecture.md`: kiến trúc và ranh giới các module.
- `api.md`: hợp đồng REST API và lỗi trả về.
- `backend-1-api.md`: API đăng nhập session, tài khoản, quyền, danh mục, đợt, thông báo và audit.
- `backend-2-api.md`: hợp đồng API backend2, request/response mẫu và flow gọi endpoint.
- `backend-3-api.md`: hợp đồng API backend3 cho tiến độ, báo cáo, hội đồng, đánh giá và kết quả.
- `backend-2-implementation-guide.md`: giải thích chi tiết backend2 theo từng thư mục, từng file, từng luồng nghiệp vụ.
- `backend-2-presentation.md`: dàn ý thuyết trình, script demo và câu trả lời ngắn cho backend2.
- `decisions/`: các quyết định kỹ thuật quan trọng.

Các tài liệu chi tiết sẽ được bổ sung cùng từng module nghiệp vụ.
